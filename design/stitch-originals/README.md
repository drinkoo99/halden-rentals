# Stitch originals

Full-size originals of the images referenced by the Stitch screens, downloaded from their
`lh3.googleusercontent.com` URLs with the `=s0` suffix (largest stored size). `NN.jpg` matches line `NN`
(0-based) of `urls.txt`.

Six URLs (17, 18, 19, 32, 36, 38) use the private `/aida/` path and require a Google sign-in, so they could
not be downloaded; the app uses local equivalents of the same cars instead (see `src/data/media.ts`).
